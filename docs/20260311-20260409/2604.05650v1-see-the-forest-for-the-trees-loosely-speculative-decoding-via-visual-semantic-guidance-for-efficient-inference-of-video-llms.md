## 摘要
视频大语言模型（Video-LLMs）在视频理解方面表现出色，但在自回归生成过程中面临高推理延迟的问题。投机解码（SD）通过采用“草稿-验证”范式来缓解这一问题，但现有方法受限于严格的精确匹配规则，严重限制了加速潜力。为了弥补这一差距，我们提出了 LVSpec，这是首个专为 Video-LLMs 量身定制的无需训练的松散投机解码框架。基于“生成过程由大量视觉无关的填充词（允许松散验证）中的稀疏视觉相关锚点（要求严格验证）所主导”这一洞察，LVSpec 采用了一种轻量级的视觉相关 Token 识别方案来准确锁定后者。为了进一步最大化接受率，我们增加了一个位置偏移容忍机制，有效地挽救了位置不匹配但语义等价的 Token。实验表明，LVSpec 实现了高保真度和高速度：它保留了超过 99.8% 的目标性能，同时将 Qwen2.5-VL-32B 的速度提升了 2.70 倍，将 LLaVA-OneVision-72B 的速度提升了 2.94 倍。值得注意的是，与针对 Video-LLMs 的最先进（SOTA）无需训练的 SD 方法相比，它将平均接受长度和加速比分别提高了 136% 和 35%。

## Abstract
Video Large Language Models (Video-LLMs) excel in video understanding but suffer from high inference latency during autoregressive generation. Speculative Decoding (SD) mitigates this by applying a draft-and-verify paradigm, yet existing methods are constrained by rigid exact-match rules, severely limiting the acceleration potential. To bridge this gap, we propose LVSpec, the first training-free loosely SD framework tailored for Video-LLMs. Grounded in the insight that generation is governed by sparse visual-relevant anchors (mandating strictness) amidst abundant visual-irrelevant fillers (permitting loose verification), LVSpec employs a lightweight visual-relevant token identification scheme to accurately pinpoint the former. To further maximize acceptance, we augment this with a position-shift tolerant mechanism that effectively salvages positionally mismatched but semantically equivalent tokens. Experiments demonstrate that LVSpec achieves high fidelity and speed: it preserves >99.8 of target performance while accelerating Qwen2.5-VL-32B by 2.70x and LLaVA-OneVision-72B by 2.94x. Notably, it boosts the mean accepted length and speedup ratio by 136% and 35% compared to SOTA training-free SD methods for Video-LLMs.

#### 1. 核心问题与整体含义（研究动机和背景）
视频大语言模型（Video-LLMs）在处理长视频时，由于自回归生成的特性以及海量的视觉 Token 输入，面临严重的推理延迟瓶颈。现有的**投机解码（Speculative Decoding, SD）**技术虽然能加速推理，但大多遵循“严格精确匹配”规则：即草稿模型生成的 Token 必须与目标模型完全一致才能被接受。
作者发现，在视频描述任务中，并非所有 Token 都同等重要。生成内容由少数**关键视觉锚点**（如具体的物体、动作词）和大量**语言填充词**（如助词、标点、通用衔接词）组成。严格匹配规则会导致大量语义正确但字面不符的填充词被拒绝，从而限制了加速比。本文旨在通过“松散验证”打破这一瓶颈。

#### 2. 方法论：核心思想与关键技术
LVSPEC 是首个专为 Video-LLMs 设计的**无需训练（Training-free）**的松散投机解码框架，核心思想是：**对视觉相关 Token 执行严格验证，对视觉无关 Token 执行松散验证。**

*   **视觉相关 Token 识别（Section 3.1）**：利用视觉投影器（Vision Projector）将视觉特征映射到文本空间。在解码每一步，计算文本隐状态与视觉隐状态的余弦相似度。通过取 Top-N 最大相似度的平均值作为“视觉相关性得分”，精准识别出承载视觉信息的关键 Token。
*   **视觉语义引导的松散验证（Section 3.2）**：引入松散参数 $\lambda$，将每步解码中得分最低的 $\lambda K$ 个 Token 视为视觉无关词。对于这些词，即使草稿模型与目标模型输出不一致，也予以接受。
*   **位置偏移容忍机制（PST, Section 3.3）**：针对视频描述中常见的语序调整或冗余词导致的错位，如果目标模型生成的 Token 出现在草稿序列的邻近范围内，则视为匹配成功，进一步提升接受长度。
