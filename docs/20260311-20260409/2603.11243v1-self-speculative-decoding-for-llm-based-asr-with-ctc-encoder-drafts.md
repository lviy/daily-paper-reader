## 摘要
我们提出了一种针对语音感知大语言模型（LLM）的自投机解码方法，通过将 CTC 编码器作为草稿模型来加速自回归（AR）推理并提高 ASR 准确率。我们的三步流程如下：（1）如果 CTC 输出分布的帧熵低于阈值，则接受贪婪 CTC 假设作为最终结果；（2）否则，使用基于 token 似然度的宽松接受标准，在单次 LLM 前向传递中验证 CTC 假设；（3）如果验证失败，则从已接受的 CTC 前缀开始恢复 AR 解码。在 9 个语料库和 5 种语言上的实验表明，该方法可以同时加速解码并降低词错率（WER）。在 HuggingFace Open ASR 基准测试中，使用 10 亿参数的 LLM 和 4.4 亿参数的 CTC 编码器，我们实现了创纪录的 5.58% WER，并将逆实时因子提高了 4.4 倍，而相比 AR 搜索，WER 仅相对增加了 12%。代码和模型权重已在宽松许可下公开。

## Abstract
We propose self-speculative decoding for speech-aware LLMs by using the CTC encoder as a draft model to accelerate auto-regressive (AR) inference and improve ASR accuracy. Our three-step procedure works as follows: (1) if the frame entropies of the CTC output distributions are below a threshold, the greedy CTC hypothesis is accepted as final; (2) otherwise, the CTC hypothesis is verified in a single LLM forward pass using a relaxed acceptance criterion based on token likelihoods; (3) if verification fails, AR decoding resumes from the accepted CTC prefix. Experiments on nine corpora and five languages show that this approach can simultaneously accelerate decoding and reduce WER. On the HuggingFace Open ASR benchmark with a 1B parameter LLM and 440M parameter CTC encoder, we achieve a record 5.58% WER and improve the inverse real time factor by a factor of 4.4 with only a 12% relative WER increase over AR search. Code and model weights are publicly available under a permissive license.

### 1. 核心问题与研究背景
*   **研究动机**：目前性能最强的语音识别（ASR）系统多为语音感知 LLM（SLM），它们采用自回归（AR）解码模式，即逐个生成 token。这种模式导致推理速度慢、计算开销大，难以满足实时应用需求。
*   **核心问题**：如何在不牺牲准确率的前提下，利用非自回归（NAR）组件加速 LLM 的推理过程。

### 2. 方法论：自投机解码（SSD）
该方法的核心思想是利用 SLM 内部已有的 **CTC 编码器** 作为“草稿模型”生成候选文本，再由 LLM 进行快速验证或修正。具体分为三个步骤：
1.  **CTC 解码与初步过滤**：
    *   使用编码器的 CTC 分类头进行贪婪解码，生成初步假设。
    *   **熵阈值判断**：计算 CTC 输出分布的帧级别熵。如果所有帧的熵都低于设定阈值 $\tau_{CTC}$（表示模型非常自信），则直接接受该结果，跳过 LLM 处理。
2.  **LLM 并行验证**：
    *   若 CTC 结果不够自信，则将其作为草稿输入 LLM。
    *   利用 LLM 的并行计算能力，在单次前向传递中计算草稿中每个 token 的似然度。
    *   **似然度过滤**：如果所有 token 的似然度均高于阈值 $\tau_{SLM}$，则接受该草稿。
3.  **自回归回退（Fallback）**：
    *   如果验证失败，找到第一个不满足阈值的 token 位置，从该位置开始恢复传统的自回归（AR）解码。

### 6. 主要结论与发现
*   **速度与精度双增**：在 Open ASR 基准上，该方法实现了 **5.58% 的 record WER**（目前最高水平），同时将推理速度提高了 **4.4 倍**。
*   **纠偏能力**：LLM 验证阶段不仅能加速，还能纠正 AR 解码中常见的“语言模型偏置”（即 LLM 倾向于生成流畅但偏离原音的内容），从而降低了词错率。
*   **阈值影响**：CTC 熵阈值对运行速度的影响比 LLM 似然度阈值更显著。

### 7. 优点与亮点
*   **无需额外模型**：巧妙复用了 SLM 架构中原有的 CTC 分量，不需要像传统投机解码那样训练专门的轻量级草稿模型。
*   **系统融合**：将 CTC 的声学鲁棒性与 LLM 的语言建模能力有机结合，通过“验证”而非单纯的“生成”来提升性能。
*   **实用性强**：提供了从“高精度”到“高吞吐”的不同配置参考，且代码和权重完全开源。

### 8. 不足与局限
*   **任务局限性**：该方法目前仅适用于 ASR 任务，无法直接应用于语音翻译或对话等需要 LLM 进行复杂推理的场景。
*   **回退开销**：如果 CTC 草稿在很靠前的位置验证失败，系统仍需进行大量的 AR 解码，对于极具挑战性的音频，加速效果会减弱。
*   **架构依赖**：要求模型必须具备 CTC 训练的编码器，对于纯 AED（注意力编码器-解码器）架构的模型不适用。
