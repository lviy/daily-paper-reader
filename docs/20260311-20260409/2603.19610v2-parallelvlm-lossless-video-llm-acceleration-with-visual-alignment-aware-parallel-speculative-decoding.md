## 摘要
尽管目前的 Video-LLM 在视频理解任务中取得了令人印象深刻的性能，但其自回归解码效率仍受限于海量的视频 token。视觉 token 剪枝可以部分缓解这一瓶颈，但现有方法仍面临信息丢失问题，且在解码加速方面效果有限。在本文中，我们提出了 ParallelVLM，这是一个无需训练的“先草拟后验证”投机解码框架，它克服了长视频场景下草拟模型与目标模型之间相互等待和加速比受限的问题。ParallelVLM 具有两个并行化阶段，可最大化硬件利用率，并结合了无偏验证器引导剪枝策略，通过消除注意力引导剪枝中的位置偏差，更好地对齐草拟模型和目标模型。大量实验表明，ParallelVLM 有效地将草拟窗口扩大了 1.6 至 1.8 倍并保持了较高的接受长度，与原始自回归解码相比，在 LLaVA-Onevision-72B 上将各种视频理解基准测试加速了 3.36 倍，在 Qwen2.5-VL-32B 上加速了 2.42 倍。

## Abstract
Although current Video-LLMs achieve impressive performance in video understanding tasks, their autoregressive decoding efficiency remains constrained by the massive number of video tokens. Visual token pruning can partially ease this bottleneck, yet existing approaches still suffer from information loss and yield only modest acceleration in decoding. In this paper, we propose ParallelVLM, a training-free draft-then-verify speculative decoding framework that overcomes both mutual waiting and limited speedup-ratio problems between draft and target models in long-video settings. ParallelVLM features two parallelized stages that maximize hardware utilization and incorporate an Unbiased Verifier-Guided Pruning strategy to better align the draft and target models by eliminating the positional bias in attention-guided pruning. Extensive experiments demonstrate that ParallelVLM effectively expands the draft window by $1.6\sim1.8\times$ with high accepted lengths, and accelerates various video understanding benchmarks by 3.36$\times$ on LLaVA-Onevision-72B and 2.42$\times$ on Qwen2.5-VL-32B compared with vanilla autoregressive decoding.

### 1. 核心问题与研究动机
*   **研究背景**：当前的视频大语言模型（Video-LLMs）在处理长视频时，会将视频编码为成千上万甚至上百万个视觉 Token。由于自回归解码的特性以及自注意力机制的平方级计算开销，海量的 Token 导致了严重的推理延迟。
*   **核心问题**：
    1.  **串行执行瓶颈**：传统的投机解码（Speculative Decoding, SD）在预填充（Prefilling）和解码阶段是串行的，导致硬件在草稿模型或目标模型工作时存在大量闲置。
    2.  **加速比与对齐的矛盾**：为了提高加速比，通常需要对草稿模型的视觉 Token 进行剪枝，但这会导致草稿模型与目标模型之间的分布偏移，降低 Token 接受率，从而抵消加速效果。
    3.  **位置偏差**：现有的注意力引导剪枝方法容易受到“注意力汇（Attention Sinks）”或位置偏差的影响，无法准确捕捉视频中的关键语义。

### 2. 方法论：ParallelVLM 框架
ParallelVLM 采用了一种无需训练、无损且并行的投机解码架构，核心包含三个关键组件：

*   **并行预填充（Parallel Prefilling, PP）**：
    *   目标模型进行全量 Token 预填充，同时草稿模型进行剪枝后的 Token 预填充。
    *   利用目标模型前几层的中间表示来指导草稿模型的剪枝，将草稿模型的启动开销完全隐藏在目标模型的延迟之下。
*   **并行解码（Parallel Decoding, PD）**：
    *   打破了“草拟-验证”的顺序依赖。在目标模型验证第 $i-1$ 轮 Token 的同时，草稿模型并行生成第 $i$ 轮的候选 Token。
    *   根据剪枝后的速度比动态调整窗口大小 $\gamma$，最大化流水线效率。
*   **无偏验证器引导剪枝（UV-Prune）**：
    *   **核心思想**：不再依赖原始注意力分数，而是观察 Token 在目标模型层间流转时与文本查询（Query）的**相似度变化（Variation）**。
    *   **技术细节**：计算视觉 Token 与文本 Token 在目标模型浅层（如前 20 层）的余弦相似度变化量。变化量大的 Token 被认为携带了关键的跨模态语义。这种方法消除了位置偏差，且完全兼容 FlashAttention。

### 5. 实验数量与充分性
*   **实验规模**：论文在 5 个不同的数据集上进行了广泛测试，涵盖了从 0.5B 到 72B 不同量级的模型组合。
*   **消融实验**：详细探讨了剪枝比例 $\alpha$ 对速度和接受率的影响、UV-Prune 与其他剪枝策略的对比、以及与 FlashAttention 的兼容性测试。

### 6. 主要结论与发现
*   **显著加速**：在 LLaVA-OV-72B 上实现了 **3.36倍** 的加速，在 Qwen2.5-VL-32B 上实现了 **2.42倍** 的加速，远超现有无损加速方法。
*   **无损保证**：通过目标模型的验证机制，ParallelVLM 在大幅提速的同时，保持了与原始自回归解码完全一致的输出分布（无损）。
*   **剪枝增益**：UV-Prune 策略能有效将草稿窗口扩大 1.6~1.8 倍，且在 90% 的高剪枝率下仍能保持稳健的 Token 接受率。
*   **硬件友好**：与 FlashAttention 结合后，在长序列（32K）下可额外获得约 1.41 倍的加速。

### 7. 优点与亮点
*   **完全并行化**：通过 PP 和 PD 阶段的设计，彻底消除了投机解码中常见的模型等待时间。
*   **创新的剪枝视角**：UV-Prune 避开了传统的注意力分数陷阱，利用层间相似度变化量作为信号，实现了更精准的视觉-文本对齐。
*   **即插即用**：无需任何微调或额外训练，适用于各种基于 Transformer 架构的 Video-LLM。

### 8. 不足与局限
*   **内存开销**：虽然加速效果显著，但由于需要同时加载草稿模型和目标模型，其显存占用比单模型自回归推理高（实验显示 72B 组合下增加了约 26GB 显存）。
*   **模型系列依赖**：为了保证较好的对齐效果，通常需要草稿模型和目标模型来自同一系列（如 Qwen 系列或 LLaVA 系列），跨系列模型的对齐表现可能受限。
*   **极端剪枝风险**：当剪枝率达到极高水平（如 >95%）时，接受率仍会出现明显下降，存在性能拐点。
