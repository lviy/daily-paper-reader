## 摘要
视频大语言模型（Video-LLMs）在视频理解方面表现卓越，但在自回归生成过程中面临高推理延迟。投机解码（SD）通过“草拟-验证”范式缓解了这一问题，但现有方法受限于严格的精确匹配规则，严重限制了加速潜力。为填补这一空白，我们提出了 LVSpec，这是首个专为 Video-LLMs 设计的无需训练的松散投机解码框架。基于“生成过程由稀疏的视觉相关锚点（需严格验证）和大量的视觉无关填充词（允许松散验证）共同主导”的洞察，LVSpec 采用了一种轻量级的视觉相关 Token 识别方案来准确定位前者。为了进一步最大化接受率，我们引入了位置偏移容忍机制，有效挽救了位置不匹配但语义等价的 Token。实验表明，LVSpec 实现了高保真度和高速度：在保留超过 99.8% 目标性能的同时，将 Qwen2.5-VL-32B 的推理速度提升了 2.70 倍，将 LLaVA-OneVision-72B 提升了 2.94 倍。值得注意的是，与针对 Video-LLMs 的最先进（SOTA）无需训练的 SD 方法相比，它将平均接受长度和加速比分别提高了 136% 和 35%。

## Abstract
Video Large Language Models (Video-LLMs) excel in video understanding but suffer from high inference latency during autoregressive generation. Speculative Decoding (SD) mitigates this by applying a draft-and-verify paradigm, yet existing methods are constrained by rigid exact-match rules, severely limiting the acceleration potential. To bridge this gap, we propose LVSpec, the first training-free loosely SD framework tailored for Video-LLMs. Grounded in the insight that generation is governed by sparse visual-relevant anchors (mandating strictness) amidst abundant visual-irrelevant fillers (permitting loose verification), LVSpec employs a lightweight visual-relevant token identification scheme to accurately pinpoint the former. To further maximize acceptance, we augment this with a position-shift tolerant mechanism that effectively salvages positionally mismatched but semantically equivalent tokens. Experiments demonstrate that LVSpec achieves high fidelity and speed: it preserves >99.8 of target performance while accelerating Qwen2.5-VL-32B by 2.70x and LLaVA-OneVision-72B by 2.94x. Notably, it boosts the mean accepted length and speedup ratio by 136% and 35% compared to SOTA training-free SD methods for Video-LLMs.

### 1. 核心问题与整体含义（研究动机和背景）
视频大语言模型（Video-LLMs）在处理长视频时，由于自回归生成的特性，面临极高的推理延迟。传统的**投机解码（Speculative Decoding, SD）**虽然能加速推理，但存在一个核心瓶颈：**严格的精确匹配规则**。即草拟模型（Drafter）生成的 Token 必须与目标模型（Verifier）完全一致才能被接受。
作者发现，在视频理解任务中，并非所有 Token 都同等重要。生成内容由少数**视觉相关锚点**（如具体的颜色、物体名）和大量**视觉无关填充词**（如助词、标点、通用动词）组成。严格匹配规则会导致大量语义正确但字面不符的填充词被拒绝，从而限制了加速比。

### 2. 方法论：LVSpec 框架
LVSpec 是首个专为 Video-LLMs 设计的**无需训练的松散投机解码框架**，核心思想是“视觉语义引导”：

*   **视觉相关 Token 识别（Section 3.1）**：利用目标模型最后一层的隐藏状态，计算文本 Token 与视觉 Token 之间的余弦相似度。为了提高区分度，仅取相似度最高的 Top-N 个视觉 Token 的平均值作为该文本 Token 的“视觉相关性得分”。
*   **视觉语义引导的松散验证（Section 3.2）**：根据得分将 Token 分类。对视觉相关性高的 Token 执行**严格验证**（必须精确匹配以防幻觉）；对相关性低的填充词执行**松散验证**（即使不匹配也允许接受）。
*   **位置偏移容忍机制（PST, Section 3.3）**：针对视频描述中常见的顺序调整或冗余词（如“the”），如果目标模型生成的 Token 出现在草拟序列的邻近范围内，则视为匹配，进一步提升接受长度。
*   **理论支撑**：论文通过数学证明，松散验证能将加速比从受限于草拟模型错误率的瓶颈中解放出来，实现与视觉密度成反比的线性扩展。
