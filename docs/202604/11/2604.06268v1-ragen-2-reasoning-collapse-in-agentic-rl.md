## 摘要
多轮大语言模型（LLM）智能体的强化学习（RL）训练本质上是不稳定的，且推理质量直接决定了任务性能。熵被广泛用于追踪推理稳定性。然而，熵仅衡量同一输入内的多样性，无法反映推理是否真正响应了不同的输入。在 RAGEN-2 中，我们发现即使在熵保持稳定的情况下，模型也可能依赖于看似多样但与输入无关的固定模板。我们将这种现象称为“模板崩溃”（template collapse），这是一种熵及所有现有指标都无法察觉的失败模式。为了诊断这一问题，我们将推理质量分解为输入内多样性（熵）和跨输入可区分性（互信息，MI），并引入了一系列互信息代理指标用于在线诊断。在多种任务中，互信息与最终性能的相关性远强于熵，使其成为更可靠的推理质量代理指标。我们进一步利用信噪比（SNR）机制解释了模板崩溃：低奖励方差会削弱任务梯度，导致正则化项占据主导地位并抹除跨输入的推理差异。为了解决这一问题，我们提出了“信噪比感知过滤”（SNR-Aware Filtering），利用奖励方差作为轻量级代理，在每次迭代中筛选高信号提示词。在规划、数学推理、网页导航和代码执行等任务中，该方法一致地提升了模型对输入的依赖性和任务性能。

## Abstract
RL training of multi-turn LLM agents is inherently unstable, and reasoning quality directly determines task performance. Entropy is widely used to track reasoning stability. However, entropy only measures diversity within the same input, and cannot tell whether reasoning actually responds to different inputs. In RAGEN-2, we find that even with stable entropy, models can rely on fixed templates that look diverse but are input-agnostic. We call this template collapse, a failure mode invisible to entropy and all existing metrics. To diagnose this failure, we decompose reasoning quality into within-input diversity (Entropy) and cross-input distinguishability (Mutual Information, MI), and introduce a family of mutual information proxies for online diagnosis. Across diverse tasks, mutual information correlates with final performance much more strongly than entropy, making it a more reliable proxy for reasoning quality. We further explain template collapse with a signal-to-noise ratio (SNR) mechanism. Low reward variance weakens task gradients, letting regularization terms dominate and erase cross-input reasoning differences. To address this, we propose SNR-Aware Filtering to select high-signal prompts per iteration using reward variance as a lightweight proxy. Across planning, math reasoning, web navigation, and code execution, the method consistently improves both input dependence and task performance.

在多轮 LLM 智能体的强化学习（RL）训练中，研究者通常使用“熵（Entropy）”来监测推理过程的稳定性。然而，本文发现了一个致命的盲点：**模板崩溃（Template Collapse）**。

*   **背景**：现有的稳定性指标（如熵、KL 散度）只能衡量单一输入下的多样性，无法检测推理是否真正根据不同输入进行了调整。这种“静默失败”会导致智能体在复杂任务中表现不佳且不可靠。

#### 2. 方法论：核心思想与关键技术
论文提出了一套从诊断到治理的完整框架：
*   **互信息（MI）诊断框架**：将推理质量分解为“输入内多样性（熵）”和“跨输入可区分性（互信息）”。
    *   **核心思想**：如果推理是针对输入的，那么给定推理链 $Z$，应该能很容易找回对应的输入 $X$。
    *   **技术细节**：引入“批次内交叉评分（In-Batch Cross-Scoring）”机制，计算推理轨迹在真实输入下的对数似然（Matched Score）与在批次内所有输入混合分布下的对数似然（Marginal Score）之差，以此作为 MI 的代理指标。
*   **信噪比（SNR）机制解释**：
    *   **理论模型**：总梯度 = 任务梯度（信号）+ 正则化梯度（噪声）。
    *   **发现**：当奖励方差（Reward Variance, RV）较低时，任务梯度变弱，而 KL 散度和熵正则化项产生的梯度保持不变，导致“噪声”主导更新，抹除了推理的输入相关性。
*   **SNR 感知过滤（SNR-Aware Filtering）**：
    *   **算法流程**：在每次训练迭代中，计算每个 Prompt 的奖励方差；根据方差对 Prompt 进行排名；使用类似核采样（Nucleus Sampling）的 Top-$p$ 策略，仅保留高方差（高信号）的 Prompt 进行参数更新。

*   **模板崩溃是普遍存在的**：在无干预的情况下，所有测试的 RL 算法都会出现推理链变短、变模板化的趋势。
*   **SNR 过滤有效性**：SNR 感知过滤在所有任务和模型规模上均实现了性能提升（平均提升约 4-7%），尤其在复杂规划任务（如 Sokoban）中提升显著。
*   **自适应性**：Top-$p$ 过滤能随训练进程自动调整保留比例，在训练后期奖励方差坍塌时自动增加选择压力。

#### 7. 优点

*   **实用性强**：提出的 SNR 过滤方法不需要额外的模型（如奖励模型或判别器），也不需要额外的推理步骤，是一种极其轻量级的即插即用方案。
*   **多模态支持**：实验扩展到了视觉语言模型（VLM），证明了该理论在多模态智能体中的普适性。

#### 8. 不足与局限
*   **对奖励函数的依赖**：该方法高度依赖于奖励方差作为信号代理。在奖励极其稀疏或环境噪声极大的情况下（如文中提到的 80% 以上随机性的 FrozenLake），奖励方差可能失效。
*   **超参数调节**：Top-$p$ 过滤中的 $p$ 值仍需针对不同任务进行一定程度的调优。
*   **探索风险**：过于激进的过滤可能会导致模型只关注容易产生奖励差异的样本，从而缩小探索范围，长期训练下的分布偏移风险仍需进一步研究。
