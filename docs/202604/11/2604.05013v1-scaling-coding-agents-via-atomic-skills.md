## 摘要
当前的大语言模型（LLM）编程智能体主要在复合基准测试（如错误修复）上进行训练，这往往导致针对特定任务的过拟合以及泛化能力受限。为解决这一问题，我们提出了一种新颖的扩展范式，将关注点从任务级优化转向原子技能的掌握。我们首先形式化了五种基础原子技能：代码定位、代码编辑、单元测试生成、问题复现和代码审查，它们作为复杂软件工程任务的基础向量。与复合编程任务相比，这些原子技能具有更强的泛化性和可组合性。随后，我们通过对原子技能进行联合强化学习（RL）来扩展编程智能体。通过这种方式，原子技能得到了持续提升，且彼此之间不存在负面干扰或权衡。值得注意的是，我们观察到这些原子技能的提升能够很好地泛化到其他未见的复合编程任务中，例如错误修复、代码重构、机器学习工程和代码安全。这一观察结果为通过原子技能训练来扩展编程智能体提供了一种新的范式。广泛的实验证明了我们所提范式的有效性。值得注意的是，我们的联合强化学习在 5 项原子技能和 5 项复合任务上的平均性能提升了 18.7%。

## Abstract
Current LLM coding agents are predominantly trained on composite benchmarks (e.g., bug fixing), which often leads to task-specific overfitting and limited generalization. To address this, we propose a novel scaling paradigm that shifts the focus from task-level optimization to atomic skill mastery. We first formalize five fundamental atomic skills, code localization, code editing, unit-test generation, issue reproduction, and code review, that serve as the basis vectors for complex software engineering tasks. Compared with composite coding tasks, these atomic skills are more generalizable and composable. Then, we scale coding agents by performing joint RL over atomic skills. In this manner, atomic skills are consistently improved without negative interference or trade-offs between them. Notably, we observe that improvements in these atomic skills generalize well to other unseen composite coding tasks, such as bug-fixing, code refactoring, machine learning engineering, and code security. The observation motivates a new scaling paradigm for coding agents by training with atomic skills. Extensive experiments demonstrate the effectiveness of our proposed paradigm. Notably, our joint RL improves average performance by 18.7% on 5 atomic skills and 5 composite tasks.

### 1. 核心问题与整体含义（研究动机和背景）
当前 LLM 编程智能体（Coding Agents）的训练主要依赖于**复合任务**（如 SWE-bench 中的完整 Bug 修复）。这种方式存在三大弊端：
*   **任务过拟合**：模型倾向于记住特定任务的启发式规则，而非掌握通用的编程能力，导致在未见过的任务（如代码重构、安全漏洞修复）上泛化性差。
*   **黑盒优化**：仅通过最终测试是否通过（Pass/Fail）作为奖励，缺乏对中间步骤（如定位、复现）的显式监督。
*   **扩展性受限**：为每种新领域定义密集的复合任务奖励函数在实践中是难以持续的。
**研究动机**：提出一种从“任务级优化”转向“原子技能掌握”的扩展范式，将复杂软件工程拆解为可组合、可评估的基础技能。

### 2. 方法论：核心思想与关键技术
核心思想是将编程能力分解为五项**原子技能**（Atomic Skills），并将其作为“基向量”通过**联合强化学习（Joint RL）**进行统一优化。

*   **五项原子技能定义**：
    1.  **代码定位 (Localization)**：给定问题描述，识别需修改的文件列表。奖励基于预测文件集与真实修改集是否完全匹配。
    2.  **代码编辑 (Editing)**：根据指令生成补丁。奖励基于单元测试和回归测试是否通过。
    3.  **单元测试生成 (UT Generation)**：为目标函数生成测试。奖励基于测试是否能在正确代码上通过，并能检测出注入的语义 Bug。
    4.  **问题复现 (Reproduction)**：编写脚本触发 Bug。奖励基于脚本在原始代码上失败但在修复后通过（由 LLM 判定日志）。
    5.  **代码审查 (Review)**：对 PR 进行总结并给出二元判断（是否修复）。奖励基于判断与真实标签的一致性。
*   **联合强化学习框架**：
    *   **统一接口**：所有技能共享相同的 Agent 接口（Bash 工具、文件替换工具）。
    *   **GRPO 算法**：采用组相对策略优化（Group-based Relative Policy Optimization），通过组内奖励归一化计算优势，减少跨技能奖励尺度不一致的问题。
    *   **统一缓冲区**：从统一的技能池中采样任务，使用单一共享策略 $\pi_\theta$ 进行优化，促进技能间的正向迁移。
