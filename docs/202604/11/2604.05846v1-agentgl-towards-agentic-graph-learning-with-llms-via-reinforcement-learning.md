## 摘要
大语言模型（LLMs）日益依赖智能体能力——如迭代检索、工具使用和决策——以克服静态参数化知识的局限性。然而，现有的智能体框架将外部信息视为非结构化文本，未能利用现实世界数据中固有的拓扑依赖关系。为了填补这一空白，我们引入了智能体图学习（Agentic Graph Learning, AGL），这是一种将图学习重新定义为拓扑感知导航与基于 LLM 推理交替进行的范式。具体而言，我们提出了 AgentGL，这是首个针对 AGL 的强化学习（RL）驱动框架。AgentGL 为 LLM 智能体配备了用于多尺度探索的图原生工具，通过搜索约束思维（search-constrained thinking）来规范工具使用以平衡准确性与效率，并采用图条件课程强化学习策略，在无需逐步监督的情况下稳定长程策略学习。在多种文本属性图（TAG）基准测试和多个 LLM 主干模型上，AgentGL 的表现显著优于强力的 GraphLLMs 和 GraphRAG 基准模型，在节点分类和链路预测中分别实现了高达 17.5% 和 28.4% 的绝对提升。这些结果表明，AGL 是使 LLM 能够在复杂关系环境中自主导航和推理的一个极具前景的前沿方向。代码已在 https://github.com/sunyuanfu/AgentGL 公开。

## Abstract
Large Language Models (LLMs) increasingly rely on agentic capabilities-iterative retrieval, tool use, and decision-making-to overcome the limits of static, parametric knowledge. Yet existing agentic frameworks treat external information as unstructured text and fail to leverage the topological dependencies inherent in real-world data. To bridge this gap, we introduce Agentic Graph Learning (AGL), a paradigm that reframes graph learning as an interleaved process of topology-aware navigation and LLM-based inference. Specifically, we propose AgentGL, the first reinforcement learning (RL)-driven framework for AGL. AgentGL equips an LLM agent with graph-native tools for multi-scale exploration, regulates tool usage via search-constrained thinking to balance accuracy and efficiency, and employs a graph-conditioned curriculum RL strategy to stabilize long-horizon policy learning without step-wise supervision. Across diverse Text-Attributed Graph (TAG) benchmarks and multiple LLM backbones, AgentGL substantially outperforms strong GraphLLMs and GraphRAG baselines, achieving absolute improvements of up to 17.5% in node classification and 28.4% in link prediction. These results demonstrate that AGL is a promising frontier for enabling LLMs to autonomously navigate and reason over complex relational environments. The code is publicly available at https://github.com/sunyuanfu/AgentGL.

#### 1. 核心问题与整体含义（研究动机和背景）
传统的图学习（Graph Learning）主要依赖图神经网络（GNNs），虽能捕捉结构但处理复杂文本语义能力有限。近期出现的 **GraphLLMs**（将图信息注入提示词）和 **GraphRAG**（基于检索增强生成）虽然引入了大语言模型（LLM），但存在以下局限：
*   **静态性**：GraphLLMs 通常在推理前一次性提取静态图上下文，无法根据推理过程动态调整搜索策略。
*   **结构缺失**：现有的智能体（Agent）框架多将外部信息视为非结构化文本，忽略了现实数据中关键的拓扑依赖（如引用关系、社交网络）。
*   **研究动机**：提出**智能体图学习（Agentic Graph Learning, AGL）**范式，让 LLM 像在互联网搜索一样，在图结构中自主导航、迭代检索证据并进行推理。

#### 2. 方法论：核心思想与技术细节
**AgentGL** 是首个由强化学习（RL）驱动的 AGL 框架，其核心流程分为两个阶段：

*   **图原生搜索策略引导（Stage 1: Policy Bootstrapping）**：
    *   **图原生工具集**：为 LLM 配备四种工具：1-hop/2-hop 邻域搜索（局部）、结构显著性搜索（基于 PageRank 的全局搜索）、图稠密搜索（基于语义相似度的全局搜索）。
    *   **奖励建模**：使用组合奖励函数 $R = r_{FMT} + r_{ACC} + r_{COV}$。其中 $r_{COV}$（覆盖奖励）鼓励智能体在初期探索所有工具，防止过早陷入单一搜索模式。
*   **搜索效率优化（Stage 2: Mitigating Search Overuse）**：
    *   **搜索约束思维（Search-Constrained Thinking）**：引入“回顾性终止触发器”，强制模型在每次搜索后评估证据是否充分；同时通过“认知密度正则化”惩罚肤浅推理，鼓励模型在减少搜索次数的同时进行深度思考。
*   **图条件课程学习（GCCL）**：
    *   利用图的固有属性（如节点度数、同质性、语义相似度）自动评估样本难度，实现从“易”到“难”的平滑训练，稳定长程策略的收敛。
*   **算法实现**：支持 **GRPO** 和 **REINFORCE++** 两种主流的无评论员（Critic-free）策略优化算法。

#### 3. 实验设计
*   **数据集**：涵盖 3 个领域的 7 个文本属性图（TAG）基准：引用网络（OGB-Arxiv, PubMed, Arxiv-2023）、亚马逊产品图（OGB-Products, Photo, Computers）、社交网络（Reddit）。
*   **任务**：节点分类（Node Classification）和链路预测（Link Prediction）。
*   **对比基准（13 种方法）**：

    *   **GraphLLMs**：LLaGA, GraphGPT, GraphICL 等。
    *   **GraphRAG**：LinearRAG, HippoRAG2, GraphCoT。
    *   **通用智能体**：Search-R1, Search-O1。
*   **设置**：在 OGB-Arxiv/Products 上训练，在所有数据集上进行域内测试和**零样本迁移（Zero-shot Transfer）**测试。

#### 4. 资源与算力
*   **硬件**：使用了 **8 张 NVIDIA H100-80G SXM5 GPU**。
*   **软件框架**：基于 OpenRLHF 进行强化学习训练。
*   **模型规模**：测试了 Qwen2.5-3B 和 7B 两种参数规模的主干模型。

#### 5. 实验数量与充分性
*   **实验规模**：实验设计非常详尽，涵盖了跨领域、跨任务、跨模型规模的对比。

#### 6. 主要结论与发现
*   **性能卓越**：AgentGL 在节点分类上最高提升 **17.5%**，在链路预测上最高提升 **28.4%**。
*   **交互式推理的优势**：相比于一次性注入上下文的静态方法，AgentGL 的“搜索-推理”循环能更有效地过滤噪声并获取关键证据。
*   **效率与准确性的平衡**：第二阶段的效率优化在减少约 **17.5% - 22%** 工具调用的同时，反而提升了预测准确率，证明了“少即是多”的搜索原则。
*   **规模效应**：随着主干模型从 3B 扩展到 7B，AgentGL 的智能体能力（尤其是零样本迁移能力）显著增强。

#### 7. 优点
*   **范式创新**：首次将图学习定义为强化学习驱动的智能体决策过程，填补了 LLM 智能体在结构化数据处理上的空白。
*   **工具设计完备**：结合了局部拓扑（1/2-hop）与全局先验（PageRank/语义），覆盖了多尺度的图信息。
*   **训练策略科学**：引入课程学习（GCCL）解决了长程策略学习难以收敛的痛点，且无需昂贵的人工标注轨迹。

#### 8. 不足与局限
*   **模态限制**：目前仅支持文本属性图，尚未扩展到包含图像、视频等多模态属性的图数据。
*   **数据分配敏感性**：两阶段训练之间的数据分配比例对最终性能有较大影响，需要精细调优。
*   **图密度挑战**：在极稠密的图结构中，工具返回的证据可能会迅速填满 LLM 的上下文窗口，存在扩展性瓶颈。
*   **应用范围**：主要针对判别式任务（分类、预测），对于生成式图任务（如子图摘要）的探讨较少。
