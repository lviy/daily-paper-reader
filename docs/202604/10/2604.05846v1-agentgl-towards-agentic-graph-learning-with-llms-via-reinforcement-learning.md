## 摘要
大语言模型（LLMs）越来越多地依赖于智能体能力——如迭代检索、工具使用和决策——来克服静态参数化知识的局限性。然而，现有的智能体框架将外部信息视为非结构化文本，未能利用现实世界数据中固有的拓扑依赖关系。为了弥补这一差距，我们引入了智能体化图学习（Agentic Graph Learning, AGL），这是一种将图学习重新定义为拓扑感知导航与基于 LLM 推理交替进行的范式。具体而言，我们提出了 AgentGL，这是首个用于 AGL 的强化学习（RL）驱动框架。AgentGL 为 LLM 智能体配备了用于多尺度探索的图原生工具，通过搜索约束思维来规范工具使用以平衡准确性与效率，并采用图条件课程强化学习策略，在无需逐步监督的情况下稳定长程策略学习。在多种文本属性图（TAG）基准测试和多个 LLM 主干模型上，AgentGL 的表现显著优于强力的 GraphLLMs 和 GraphRAG 基准模型，在节点分类中实现了高达 17.5% 的绝对提升，在链路预测中实现了 28.4% 的绝对提升。这些结果表明，AGL 是使 LLM 能够在复杂关系环境中自主导航和推理的一个极具前景的前沿方向。代码已在 https://github.com/sunyuanfu/AgentGL 公开。

## Abstract
Large Language Models (LLMs) increasingly rely on agentic capabilities-iterative retrieval, tool use, and decision-making-to overcome the limits of static, parametric knowledge. Yet existing agentic frameworks treat external information as unstructured text and fail to leverage the topological dependencies inherent in real-world data. To bridge this gap, we introduce Agentic Graph Learning (AGL), a paradigm that reframes graph learning as an interleaved process of topology-aware navigation and LLM-based inference. Specifically, we propose AgentGL, the first reinforcement learning (RL)-driven framework for AGL. AgentGL equips an LLM agent with graph-native tools for multi-scale exploration, regulates tool usage via search-constrained thinking to balance accuracy and efficiency, and employs a graph-conditioned curriculum RL strategy to stabilize long-horizon policy learning without step-wise supervision. Across diverse Text-Attributed Graph (TAG) benchmarks and multiple LLM backbones, AgentGL substantially outperforms strong GraphLLMs and GraphRAG baselines, achieving absolute improvements of up to 17.5% in node classification and 28.4% in link prediction. These results demonstrate that AGL is a promising frontier for enabling LLMs to autonomously navigate and reason over complex relational environments. The code is publicly available at https://github.com/sunyuanfu/AgentGL.

*   **核心问题**：现有的图学习方法（GNNs）缺乏文本语义处理能力，而现有的图大模型（GraphLLMs）通常依赖静态的图上下文，无法在推理过程中根据需要动态、自主地探索图结构。

### 2. 方法论：核心思想与技术细节
AgentGL 是首个由强化学习（RL）驱动的 AGL 框架，其核心由三个部分组成：
*   **图原生搜索策略引导（Policy Bootstrapping）**：
    *   为 LLM 配备了一套图原生工具集：**1-hop/2-hop 邻域搜索**（局部感知）、**结构显著性搜索**（基于 PageRank 的全局感知）和**图稠密搜索**（基于语义向量的检索）。
    *   采用“思考-行动-观察”循环，通过奖励建模（格式奖励、准确性奖励、工具覆盖奖励）引导模型学会使用这些工具。
*   **搜索效率优化（Mitigating Search Overuse）**：
    *   提出“**搜索约束思维（Search-Constrained Thinking）**”，通过引入“回顾性终止触发器”和“认知密度正则化”，强制模型在调用新工具前深入分析已有证据，减少冗余搜索，平衡准确性与计算成本。
*   **图条件课程学习（GCCL）**：
    *   利用图的固有属性（如节点度数、同质性、语义相似度与标签的一致性）自动评估样本难度。
    *   训练过程遵循“由易到难”的顺序，以稳定长程策略学习并加速收敛。
*   **算法实现**：支持 GRPO 和 REINFORCE++ 两种主流的无评论家（critic-free）策略优化算法。

### 3. 实验设计
*   **数据集**：涵盖 3 个领域的 7 个文本属性图（TAG）基准：
    *   引用网络：OGB-Arxiv, PubMed, Arxiv-2023。
    *   亚马逊产品图：OGB-Products, Amazon-Photo, Amazon-Computers。
    *   社交网络：Reddit。
*   **任务场景**：节点分类（Node Classification）和链路预测（Link Prediction），包括**域内评估**和**零样本迁移（Zero-shot Transfer）**。
*   **对比方法（13 种基准）**：

    *   标准智能体搜索：Search-R1, Search-O1。
    *   基础模型：Qwen2.5-Instruct (3B/7B)。

### 4. 资源与算力
*   **硬件环境**：实验在一台配备 **8 张 NVIDIA H100-80G SXM5 GPU** 的节点上运行。
*   **软件框架**：使用 Open-RLHF 作为主要的强化学习训练框架。
*   **训练细节**：学习率设为 2e-6，最大序列长度 1600，每个 Prompt 采样 16 个 Rollout。具体训练时长未明确说明，但提到了 GCCL 能显著加速收敛。

### 5. 实验数量与充分性
*   **实验规模**：在 7 个数据集上进行了详尽测试，涵盖了从 3B 到 7B 不同参数规模的 LLM 主干。
*   **消融实验**：针对 RL 训练阶段（引导 vs. 效率优化）、奖励项（rCOV, RTT, CDR）以及课程学习（GCCL）均做了深入的消融分析。
*   **客观性与公平性**：所有基准模型均使用相同的主干模型（Qwen2.5），并为标准智能体基准提供了相同的图搜索空间，确保了对比的公正性。

### 6. 主要结论与发现
*   **性能卓越**：AgentGL 在节点分类上平均提升 12.7%-24.4%，在链路预测上平均提升 22.4%-26.3%，显著优于静态上下文填充的方法。
*   **效率与准确性的平衡**：通过第二阶段的效率优化，模型在减少约 17.5% 工具调用的同时，准确率反而提升了约 2.4%-3%。
*   **泛化能力强**：在零样本迁移实验中，AgentGL 表现出极强的鲁棒性，证明了其学习到的是通用的图导航和推理策略，而非简单的过拟合。
*   **规模效应**：随着主干模型从 3B 扩展到 7B，AgentGL 的性能增益更加明显，尤其是在处理复杂拓扑关系时。

### 7. 优点（亮点）
*   **范式创新**：首次将图学习定义为智能体化的自主导航过程，打破了传统静态图表征的限制。
*   **训练策略科学**：结合了课程学习（GCCL）和两阶段 RL，解决了长程决策中缺乏步骤级监督和容易陷入局部最优的问题。
*   **工具设计完备**：涵盖了从局部到全局、从结构到语义的多个维度，使 LLM 具备了全方位的图感知能力。

### 8. 不足与局限
*   **多模态限制**：目前仅支持文本属性图，尚未扩展到包含图像或其他模态信息的图数据。
*   **训练复杂性**：两阶段 RL 训练对数据分配和超参数调节（如准确性与效率的权衡）较为敏感。
*   **图密度挑战**：在极稠密的图中，搜索空间会急剧膨胀，目前的工具调用预算（Budget）可能面临挑战。
*   **推理成本**：作为智能体框架，其推理时的 Token 消耗和延迟必然高于传统的 GNN 或单次调用的 GraphLLM。
