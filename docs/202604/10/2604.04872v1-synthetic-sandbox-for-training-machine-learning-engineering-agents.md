## 摘要
随着大语言模型智能体从软件工程（SWE）任务向机器学习工程（MLE）任务迈进，验证智能体行为的成本呈数量级增长：SWE 任务可以通过快速执行的单元测试进行验证，而 MLE 验证则需要在每个采样步骤中在大型数据集上运行完整的机器学习流水线——包括数据预处理、模型训练和指标评估——这使得基于轨迹的在线强化学习（on-policy RL）变得极其缓慢。现有方法退而求其次，采用监督微调（SFT）或离线代理奖励，牺牲了在线强化学习在探索和泛化方面的优势。我们观察到，沙盒数据规模是这一瓶颈的主要来源。基于这一洞察，我们提出了 SandMLE，这是一个多智能体框架，能够从少量种子任务中生成多样化且可验证的合成 MLE 环境，在保留现实世界问题的结构和技术复杂性的同时，将数据集限制在微观规模（每个任务仅配有 50-200 个训练样本）。通过广泛的实验，我们证明 SandMLE 将执行时间缩短了 13 倍以上，首次在 MLE 领域实现了大规模、基于轨迹的在线强化学习。在 MLE-bench-lite 上，SandMLE 在 Qwen3-8B、14B 和 30B-A3B 模型上均取得了优于 SFT 基线的显著收益，相对奖牌率提升在 20.3% 到 66.9% 之间。此外，训练后的策略可以泛化到未见的智能体脚手架，在 MLE-Dojo 上的 HumanRank 评分提升高达 32.4%。

## Abstract
As large language model agents advance beyond software engineering (SWE) tasks toward machine learning engineering (MLE), verifying agent behavior becomes orders of magnitude more expensive: while SWE tasks can be verified via fast-executing unit tests, MLE verification requires running full ML pipelines -- data preprocessing, model training, and metric evaluation -- on large datasets at each rollout step, rendering trajectory-wise on-policy reinforcement learning (RL) prohibitively slow. Existing approaches retreat to supervised fine-tuning (SFT) or offline proxy rewards, sacrificing the exploration and generalization benefits of on-policy RL. We observe that sandbox data size is the primary source of this bottleneck. Based on this insight, we introduce SandMLE, a multi-agent framework that generates diverse, verifiable synthetic MLE environments from a small number of seed tasks, preserving the structural and technical complexity of real-world problems while constraining datasets to micro-scale (each task is paired with only 50-200 training samples). Through extensive experiments, we show that SandMLE reduces execution time by over 13 times, enabling large-scale, on-policy trajectory-wise RL for the first time in the MLE domain. On MLE-bench-lite, SandMLE yields significant gains over SFT baselines across Qwen3-8B, 14B, and 30B-A3B, with relative medal rate improvements ranging from 20.3% to 66.9%. Furthermore, the trained policy generalizes across unseen agentic scaffolds, achieving up to 32.4% better HumanRank score on MLE-Dojo.

*   **现有局限**：由于执行速度极慢，现有的 MLE 智能体训练大多依赖于监督微调（SFT）或离线代理奖励，无法利用在线强化学习（On-policy RL）带来的探索和泛化优势。
*   **研究目标**：通过缩减数据集规模但保留任务复杂度，构建一个高速执行的“合成沙盒”，使大规模在线强化学习在 MLE 领域成为可能。

### 2. 方法论：SandMLE 框架
*   **核心思想**：利用多智能体协作，从少量真实世界的“种子任务”中提取“结构 DNA”，生成微缩规模（50-200 个样本）但逻辑复杂的合成任务。
*   **关键技术细节（四阶段流水线）**：

    4.  **技术作家 (Technical Writer)**：合成最终的任务说明文档，确保提示词与环境完全对齐。

*   **奖励设计**：设计了**基于里程碑的密集奖励**，包括格式奖励、执行奖励以及分层性能奖励（对应 Kaggle 的铜、银、金牌水平），以解决奖励稀疏问题。

*   **数据集/基准**：

*   **评估指标**：有效提交率（Valid Sub.）、中位数以上率（Above Median）、奖牌率（Any Medal）以及 HumanRank 评分。

*   **GPU 型号与数量**：训练使用 **NVIDIA H200 GPU**。

*   **效率提升**：SandMLE 将平均执行时间从 196.17 秒缩短至 **14.31 秒**，实现了 **13.7 倍** 的加速。
*   **推理限制**：测试时每个任务限制在 24 GPU 小时内完成。

### 5. 实验数量与充分性
*   **实验规模**：涵盖了从 8B 到 30B 不同参数规模的模型，并在两个独立的第三方基准（MLE-bench 和 MLE-Dojo）上验证。
*   **消融实验**：专门针对“里程碑奖励设计”进行了消融研究，对比了稀疏奖励与密集奖励的效果。
*   **泛化性测试**：在不同的智能体脚手架（ReAct, AIDE, AIRA, MLE-Agent）上进行了交叉验证。
*   **充分性评价**：实验设计较为全面，不仅验证了性能提升，还探讨了测试时缩放（Test-time scaling）和训练动力学，结果具有较强的说服力。

### 6. 主要结论与发现
*   **性能飞跃**：SandMLE 在所有模型规模上均显著优于 SFT 基线，30B 模型的奖牌率相对提升高达 66.9%。
*   **RL 优于 SFT**：单纯的 SFT 往往只能学会格式，而通过 SandMLE 进行的在线 RL 能显著提升模型解决复杂工程问题的内在推理能力。
*   **强泛化性**：在合成沙盒上训练的模型能够很好地迁移到真实的、大规模的数据集任务中，并能适应未见的智能体框架。
*   **测试时缩放**：模型展现出随思考轮数增加而性能提升的趋势，但受限于上下文窗口长度，过长的交互会导致性能回落。

### 7. 优点
*   **创新性解决瓶颈**：通过“微缩合成环境”这一巧妙思路，解决了 MLE 领域在线强化学习不可行的核心痛点。
*   **端到端自动化**：构建了从任务抽象到数据生成、环境配置、文档编写的全自动流水线。
*   **框架无关性**：证明了强化学习提升的是模型底层的工程能力，而非对特定脚手架的过拟合。

### 8. 不足与局限
*   **上下文窗口限制**：实验发现，当交互轮数过多时，上下文窗口溢出会成为性能瓶颈，目前的动态截断策略仍有改进空间。
*   **合成与真实的差距**：虽然微缩数据集保留了结构复杂度，但某些依赖“大数据特性”（如极度稀疏特征、超大规模类别）的特定 MLE 技巧可能无法在沙盒中完全习得。
*   **算力门槛**：尽管加速了 13 倍，但大规模 GRPO 训练依然需要大量的 H200 算力支持，对普通研究者门槛较高。
