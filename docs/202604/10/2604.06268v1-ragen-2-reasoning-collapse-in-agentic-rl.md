## 摘要
多轮大语言模型（LLM）智能体的强化学习（RL）训练本质上是不稳定的，而推理质量直接决定了任务性能。熵被广泛用于追踪推理的稳定性。然而，熵仅衡量同一输入内的多样性，无法判断推理是否真正响应了不同的输入。在 RAGEN-2 中，我们发现即使熵保持稳定，模型也可能依赖于固定的模板，这些模板看起来具有多样性，但与输入无关。我们将此称为“模板崩溃”（template collapse），这是一种熵和所有现有指标都无法察觉的失效模式。为了诊断这一失效，我们将推理质量分解为输入内多样性（熵）和跨输入可区分性（互信息，MI），并引入了一系列互信息代理指标用于在线诊断。在各种任务中，互信息与最终性能的相关性远强于熵，使其成为更可靠的推理质量代理指标。我们进一步利用信噪比（SNR）机制解释了模板崩溃。低奖励方差会削弱任务梯度，导致正则化项占据主导地位并抹除跨输入的推理差异。为解决这一问题，我们提出了 SNR 感知过滤（SNR-Aware Filtering），利用奖励方差作为轻量级代理，在每次迭代中筛选高信号提示词。在规划、数学推理、网页导航和代码执行等任务中，该方法一致地提升了输入依赖性和任务性能。

## Abstract
RL training of multi-turn LLM agents is inherently unstable, and reasoning quality directly determines task performance. Entropy is widely used to track reasoning stability. However, entropy only measures diversity within the same input, and cannot tell whether reasoning actually responds to different inputs. In RAGEN-2, we find that even with stable entropy, models can rely on fixed templates that look diverse but are input-agnostic. We call this template collapse, a failure mode invisible to entropy and all existing metrics. To diagnose this failure, we decompose reasoning quality into within-input diversity (Entropy) and cross-input distinguishability (Mutual Information, MI), and introduce a family of mutual information proxies for online diagnosis. Across diverse tasks, mutual information correlates with final performance much more strongly than entropy, making it a more reliable proxy for reasoning quality. We further explain template collapse with a signal-to-noise ratio (SNR) mechanism. Low reward variance weakens task gradients, letting regularization terms dominate and erase cross-input reasoning differences. To address this, we propose SNR-Aware Filtering to select high-signal prompts per iteration using reward variance as a lightweight proxy. Across planning, math reasoning, web navigation, and code execution, the method consistently improves both input dependence and task performance.

### 2. 方法论：互信息诊断与 SNR 感知过滤
*   **核心思想**：将推理质量拆解为两个维度：**输入内多样性（熵）**和**跨输入依赖性（互信息，MI）**。通过提升信噪比（SNR）来防止正则化项抹除输入相关的推理特征。
*   **关键技术细节**：
    *   **互信息代理指标（MI Proxy）**：提出一种基于“批次内交叉评分（In-Batch Cross-Scoring）”的方法。计算推理轨迹 $Z$ 在其原始输入 $X_i$ 下的对数似然（Matched Score）与在批次内所有输入混合分布下的对数似然（Marginal Score）之差。如果两者接近，说明推理已与输入无关，发生了模板崩溃。
    *   **SNR 机制解释**：论文通过梯度分解证明，当同一提示词下的奖励方差（Reward Variance, RV）较低时，任务梯度（信号）会被采样噪声和正则化梯度（如 KL 散度、熵奖励）淹没。
    *   **SNR 感知过滤（SNR-Aware Filtering）**：在每次训练迭代中，计算每个 Prompt 的奖励方差。使用类似核采样（Nucleus Sampling）的 **Top-$p$ 过滤策略**，仅保留高方差（高信号）的 Prompt 进行参数更新，剔除那些只会引入正则化噪声的低信号样本。

### 6. 主要结论与发现
*   **MI 是更好的监控器**：互信息（MI）与任务成功率的正相关性（+0.39）远高于熵（-0.14），是诊断推理崩溃的有效早期预警信号。
*   **奖励方差决定信号质量**：低奖励方差会导致正则化项主导更新方向，从而诱发模板崩溃。

### 7. 优点
*   **理论深刻**：首次系统性地定义并量化了智能体 RL 中的“模板崩溃”现象，并给出了基于 SNR 的梯度层面的解释。
*   **实用性强**：提出的过滤方法不需要额外的模型（如奖励模型或判别器），也不需要额外的推理步骤，易于集成到现有的 RL 流程中。
*   **诊断工具化**：提供的 MI 代理指标家族为未来智能体训练提供了比熵更科学的监控手段。

### 8. 不足与局限
*   **环境依赖性**：该方法依赖于奖励方差作为信号代理。在奖励极其稀疏或环境噪声极大的极端情况下（如文中提到的 80% 以上随机性的 FrozenLake），奖励方差可能失效。
*   **多样性风险**：过度激进的过滤（极小的 $p$ 值）可能会导致模型只在部分容易产生差异的 Prompt 上过拟合，缩小探索覆盖面。
*   **单智能体限制**：目前实验仅限于单智能体场景，尚未探讨多智能体强化学习中是否存在类似的模板崩溃传播现象。
