## 摘要
以角色为中心的记忆（persona-centric memory）的最新进展揭示了多智能体系统在管理角色记忆方面的强大能力，特别是在对话场景中。然而，这些复杂的框架通常面临信息丢失的问题，且在不同场景下表现脆弱，导致性能欠佳。在本文中，我们提出了 DeltaMem，这是一个代理式记忆管理系统，它将以角色为中心的记忆管理建模为单智能体设置下的端到端任务。为了进一步提高代理式记忆管理器的性能，我们从人类记忆的演化中汲取灵感，合成了一个用户-助手对话数据集，并附带相应的操作级记忆更新标签。在此基础上，我们引入了一种新颖的基于记忆的 Levenshtein 距离来形式化记忆更新奖励，并提出了一种定制的强化学习框架，以进一步增强 DeltaMem 的管理能力。广泛的实验表明，无需训练的 DeltaMem 和经过强化学习训练的 DeltaMem 在包括 LoCoMo、HaluMem 和 PersonaMem 在内的多种长期记忆基准测试中，均优于所有产品级基准模型。

## Abstract
Recent advances in persona-centric memory have revealed the powerful capability of multi-agent systems in managing persona memory, especially in conversational scenarios. However, these complex frameworks often suffer from information loss and are fragile across varying scenarios, resulting in suboptimal performance. In this paper, we propose DeltaMem, an agentic memory management system that formulates persona-centric memory management as an end-to-end task within a single-agent setting. To further improve the performance of our agentic memory manager, we draw inspiration from the evolution of human memory and synthesize a user-assistant dialogue dataset along with corresponding operation-level memory updating labels. Building on this, we introduce a novel Memory-based Levenshtein Distance to formalize the memory updating reward, and propose a tailored reinforcement learning framework to further enhance the management capabilities of DeltaMem. Extensive experiments show that both training-free and RL-trained DeltaMem outperform all product-level baselines across diverse long-term memory benchmarks, including LoCoMo, HaluMem, and PersonaMem.

#### 1. 核心问题与整体含义（研究动机和背景）
随着大语言模型（LLM）在个性化场景中的应用增加，如何构建长期的人格化记忆管理系统成为关键。现有的系统（如 Mem0）多采用**多智能体模块化架构**（将任务拆分为提取、检索、更新三个步骤）。
*   **研究动机**：作者指出，模块化设计在长程交互中会导致“级联信息衰减”，即信息在不同智能体间传递时会丢失细微的上下文。
*   **核心问题**：如何减少记忆管理过程中的信息损失，并解决缺乏操作级（Operation-level）训练数据以及强化学习中奖励稀疏的问题。

#### 2. 方法论：核心思想与关键技术
DeltaMem 将记忆管理重新定义为**单智能体端到端任务**，主要包含以下三个核心支柱：
*   **DeltaMem 框架**：采用 **ReAct（Reasoning and Act）** 范式。智能体不再是被动执行提取或更新，而是自主推理需要检索哪些记忆、如何整合新信息，并直接输出更新操作（Add, Update, None）。
*   **记忆演化引导的数据合成**：受人类记忆演化启发，通过四个步骤（画像丰富、事件生成、记忆生成、对话生成）合成数据。特别引入了**事件内演化**（属性调整）和**事件间演化**（情感/意义的回溯性重构），从而获得带有精确操作标签的对话数据集。
*   **基于状态转移的强化学习（RL）**：
    *   **核心指标**：提出**基于记忆的 Levenshtein 距离**。它不直接对比操作指令，而是对比操作后的“记忆状态”差异。
    *   **关键技术**：利用**最优传输（Optimal Transport）**解决语义等价性，并引入**局部词汇保真度（Local Lexical Fidelity）**，通过关键词覆盖率来确保事实的准确性。
    *   **奖励函数**：由格式奖励（0.1）、检索奖励（0.1）和基于状态转移的 Soft F1 分数奖励（0.8）组成。

#### 6. 主要结论与发现
*   **单智能体优势**：即使不经过训练，单智能体架构的 DeltaMem 在多个指标上已优于复杂的多智能体系统。
*   **RL 显著提升**：经过 RL 训练后，DeltaMem-8B-RL 在 LoCoMo 上的 LLM-as-a-Judge 得分达到 75.13，显著超过 LightMem（66.43）和 Zep（65.99）。

*   **稳定性**：在 HaluMem 的长程测试中，DeltaMem 随会话增加的性能下降速度远慢于基准模型，表现出更强的鲁棒性。

#### 7. 优点（亮点）
*   **架构简化**：将复杂的模块化流程简化为端到端推理，减少了中间环节的信息损耗。
*   **奖励设计创新**：通过“记忆编辑距离”将离散的操作评估转化为连续的语义状态评估，有效解决了 RL 训练中的奖励稀疏问题。
*   **高质量合成数据**：模拟人类记忆演化的逻辑为缺乏真实用户日志的领域提供了高质量的替代方案。

#### 8. 不足与局限
*   **合成数据偏差**：虽然使用了 PersonaHub 增加多样性，但合成数据仍可能携带基础模型的社会偏见或刻板印象。
*   **超参数敏感性**：奖励模型中的相似度阈值 $\tau$ 对最终性能有一定影响，需要针对不同领域进行微调。
*   **应用限制**：目前主要在 Qwen 系列模型上验证，对于更小规模模型或不同架构模型的迁移效果尚待进一步验证。
