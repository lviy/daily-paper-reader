## 摘要
智能体技能是程序性知识和可执行资源的结构化包，智能体在推理时动态加载这些技能，已成为增强大语言模型（LLM）智能体的可靠机制。然而，推理时的技能增强存在根本局限：检索噪声会引入无关指导，注入的技能内容会带来巨大的 Token 开销，且模型从未真正习得它仅仅是在遵循的知识。我们探讨技能是否可以内化到模型参数中，从而在无需任何运行时技能检索的情况下实现零样本自主行为。我们提出了 SKILL0，这是一个专为技能内化设计的上下文强化学习框架。SKILL0 引入了一种训练阶段的课程学习方案，从完整的技能上下文开始并逐步将其撤出。技能在离线状态下按类别分组，并与交互历史一起渲染成紧凑的视觉上下文，教导模型进行工具调用和多轮任务完成。随后，动态课程评估每个技能文件的同策略辅助作用，在随线性衰减的预算内，仅保留当前策略仍能从中获益的技能，直到智能体在完全零样本的设置下运行。广泛的智能体实验表明，SKILL0 相比标准强化学习基线取得了显著提升（ALFWorld 提升 9.7%，Search-QA 提升 6.6%），同时保持了每步少于 0.5k Token 的高效上下文。我们的代码可在 https://github.com/ZJU-REAL/SkillZero 获取。

## Abstract
Agent skills, structured packages of procedural knowledge and executable resources that agents dynamically load at inference time, have become a reliable mechanism for augmenting LLM agents. Yet inference-time skill augmentation is fundamentally limited: retrieval noise introduces irrelevant guidance, injected skill content imposes substantial token overhead, and the model never truly acquires the knowledge it merely follows. We ask whether skills can instead be internalized into model parameters, enabling zero-shot autonomous behavior without any runtime skill retrieval. We introduce SKILL0, an in-context reinforcement learning framework designed for skill internalization. SKILL0 introduces a training-time curriculum that begins with full skill context and progressively withdraws it. Skills are grouped offline by category and rendered with interaction history into a compact visual context, teaching he model tool invocation and multi-turn task completion. A Dynamic Curriculum then evaluates each skill file's on-policy helpfulness, retaining only those from which the current policy still benefits within a linearly decaying budget, until the agent operates in a fully zero-shot setting. Extensive agentic experiments demonstrate that SKILL0 achieves substantial improvements over the standard RL baseline (+9.7\% for ALFWorld and +6.6\% for Search-QA), while maintaining a highly efficient context of fewer than 0.5k tokens per step. Our code is available at https://github.com/ZJU-REAL/SkillZero.

### SKILL0：面向技能内化的上下文智能体强化学习论文总结

#### 1. 核心问题与整体含义（研究动机和背景）
当前提升大语言模型（LLM）智能体能力的主流范式是**推理时技能增强**（Inference-time Skill Augmentation），即通过检索算法从技能库中提取相关操作指南并注入 Prompt。然而，这种方式存在三个根本缺陷：
*   **检索噪声**：错误的技能检索会引入误导性信息。
*   **Token 开销**：长篇累牍的技能描述在多轮对话中累积，导致推理成本激增。
*   **缺乏真正习得**：模型只是在“遵循指令”而非“掌握知识”，能力停留在上下文层面而非参数层面。

**SKILL0 的核心目标**是实现“训练时有技能，推理时零技能”（Skills at training, zero at inference），通过强化学习将外部技能**内化**到模型参数中，使智能体在推理阶段无需检索即可具备高效的自主行为能力。

#### 2. 方法论：核心思想与技术细节
SKILL0 提出了一种**上下文强化学习（In-Context Reinforcement Learning, ICRL）**框架，结合动态课程学习实现技能转移：

*   **视觉上下文渲染（Context Rendering）**：为了降低 Token 压力，SKILL0 将文本交互历史和技能描述渲染为紧凑的图像，利用视觉编码器生成视觉 Token。模型可以自主决定压缩率 $c_t$，在任务成功率和 Token 效率之间取得平衡。
*   **动态课程学习（Dynamic Curriculum）**：
    1.  **技能分组**：离线将技能按类别（如“清洁”、“搜索”）分组，并关联特定的验证子任务。
    2.  **辅助性评估（Helpfulness Evaluation）**：在训练过程中，定期评估每个技能文件对当前策略的贡献度 $\Delta k$（即“有技能时的准确率”减去“无技能时的准确率”）。
    3.  **线性预算衰减**：设定一个随训练阶段线性减少的技能数量预算 $M(s)$。
    4.  **过滤与排序**：仅保留 $\Delta k > 0$ 的技能，并按贡献度排序，选取前 $M(s)$ 个进入训练上下文。
*   **强化学习目标**：采用类似 GRPO 的算法，优化复合奖励函数（任务成功奖励 + 压缩效率奖励），通过 KL 散度约束防止策略坍缩。

#### 5. 实验数量与充分性
论文进行了较为充分的实验验证：
*   **多维度对比**：在两个截然不同的领域（具身模拟与知识问答）验证了通用性。
*   **消融实验**：针对技能预算策略（如固定预算 vs 衰减预算）、动态课程的三个步骤（过滤、排序、选择）以及验证间隔 $d$ 进行了详细测试。
*   **客观性**：通过监控“有/无技能”下的验证曲线，清晰展示了技能从“外部辅助”到“内部掌握”的转化过程，实验设计逻辑严密。

#### 6. 主要结论与发现
*   **性能超越基准**：在零样本推理设置下，SKILL0 在 ALFWorld 上比 AgentOCR 提升了 **9.7%**，在 Search-QA 上提升了 **6.6%**。
*   **极高的 Token 效率**：由于技能已内化且采用了视觉压缩，SKILL0 推理时的每步 Token 消耗**低于 0.5k**，比 SkillRL 等方法降低了 5 倍以上。
*   **技能内化趋势**：实验观察到技能的“辅助性”随训练呈现先升后降的趋势，证明模型在后期已不再依赖外部 Prompt 即可完成复杂任务。

#### 7. 优点：亮点设计
*   **范式创新**：首次将“技能内化”作为显式的强化学习训练目标，解决了智能体对长 Prompt 的依赖问题。
*   **动态自适应**：动态课程学习不是机械地删除技能，而是根据模型当前的“学习状态”自适应地撤走脚手架。
*   **视觉压缩集成**：巧妙地利用多模态模型的视觉能力处理长历史，进一步优化了智能体的运行效率。

#### 8. 不足与局限
*   **初始依赖**：SKILL0 的效果高度依赖于初始技能库（SkillBank）的质量，如果初始技能本身有误，内化过程可能会固化错误的策略。
*   **分组开销**：离线技能分组和验证子任务的划分需要一定的人工干预或领域知识，迁移到全新领域时存在冷启动成本。
*   **泛化边界**：虽然在域外数据集（如 Bamboogle）表现良好，但对于完全未见过的全新技能类型的泛化能力仍需进一步探讨。
