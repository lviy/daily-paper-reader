## 摘要
部署在智能体环境中的大语言模型（LLMs）必须在不同的任务实例中运用多种能力，其中“能力”被定义为在轨迹中执行一个或多个动作，这些动作对于成功解决环境中的特定任务子集至关重要。许多现有方法要么依赖于并非针对模型在目标环境中实际能力缺陷的合成训练数据，要么直接在目标环境上进行训练，使得模型需要跨任务隐式地学习这些能力。我们提出了 TRACE（将智能体重复失败转化为面向能力的训练环境），这是一个用于特定环境智能体自我提升的端到端系统。TRACE 通过对比成功和失败的轨迹来自动识别缺失的能力，并为每种能力合成一个针对性的训练环境（该环境根据是否行使了该能力提供奖励），随后在每个合成环境上通过强化学习（RL）训练 LoRA 适配器，并在推理时路由至相关的适配器。实验结果表明，TRACE 在不同环境中具有良好的泛化性，在 $τ^2$-bench（客户服务）上比基础智能体提升了 14.1 分，在 ToolSandbox（工具使用）上增加了 7 个满分，分别比最强基准模型高出 7.4 分和 4 个满分。在相同数量的采样（rollouts）下，TRACE 的扩展效率高于基准模型，在 $τ^2$-bench 上分别比 GRPO 和 GEPA 高出 9.2 分和 7.4 分。

## Abstract
Large Language Models (LLMs) deployed in agentic environments must exercise multiple capabilities across different task instances, where a capability is performing one or more actions in a trajectory that are necessary for successfully solving a subset of tasks in the environment. Many existing approaches either rely on synthetic training data that is not targeted to the model's actual capability deficits in the target environment or train directly on the target environment, where the model needs to implicitly learn the capabilities across tasks. We introduce TRACE (Turning Recurrent Agent failures into Capability-targeted training Environments), an end-to-end system for environment-specific agent self-improvement. TRACE contrasts successful and failed trajectories to automatically identify lacking capabilities, synthesizes a targeted training environment for each that rewards whether the capability was exercised, and trains a LoRA adapter via RL on each synthetic environment, routing to the relevant adapter at inference. Empirically, TRACE generalizes across different environments, improving over the base agent by +14.1 points on $τ^2$-bench (customer service) and +7 perfect scores on ToolSandbox (tool use), outperforming the strongest baseline by +7.4 points and +4 perfect scores, respectively. Given the same number of rollouts, TRACE scales more efficiently than baselines, outperforming GRPO and GEPA by +9.2 and +7.4 points on $τ^2$-bench.

### 1. 核心问题与研究动机
*   **研究背景**：LLM 智能体在复杂环境（如客服、编程）中需要多种核心能力（如数据检索、工具调用精度）。
*   **核心问题**：现有的改进方法（如直接在目标环境进行强化学习或使用通用的合成数据）效率低下。原因在于：
    1.  **反馈稀疏**：目标环境的成功/失败信号无法明确指出是哪种底层能力缺失。
    2.  **缺乏针对性**：通用合成数据可能无法覆盖模型在特定任务中的实际短板。
*   **研究动机**：通过对比分析模型自身的失败案例，自动“对症下药”，构建专门的训练环境来强化缺失的能力。

### 2. 方法论（TRACE 流程）
TRACE 系统包含四个关键阶段：
1.  **对比式能力识别 (Contrastive Identification)**：
    *   将智能体的轨迹分为成功组和失败组。
    *   利用 LLM 分析器识别出能显著区分两组的“能力缺陷”。
    *   计算**对比间隙 (Contrastive Gap)**：即某项能力在失败轨迹中缺失的频率与在成功轨迹中缺失频率之差，以此筛选高影响力的能力。
2.  **针对性环境合成 (Environment Synthesis)**：
    *   为每种识别出的能力缺陷自动编写一个合成训练环境。
    *   环境包含：程序化任务生成器（基于随机种子）、模拟交互逻辑和自动验证器（奖励函数）。
    *   **核心要求**：环境必须隔离单一能力，且奖励信号要密集且可验证。
3.  **强化学习训练 (RL Training)**：
    *   针对每个合成环境，冻结基础模型，训练一个独立的 **LoRA 适配器**。
    *   使用 **GRPO (Group Relative Policy Optimization)** 算法，通过组内相对奖励来优化策略，无需额外的价值模型。
4.  **能力组合与路由 (Routing)**：
    *   在推理时，使用基础模型作为一个“路由器”，根据任务描述选择最匹配的 LoRA 适配器。

*   **性能显著提升**：TRACE 在 $\tau^2$-Bench 上比基础模型提升了 **14.1%** 的成功率，在 ToolSandBox 上显著增加了满分案例。
*   **扩展效率高**：在相同的采样数量下，TRACE 的表现优于直接在目标环境训练的 GRPO 和提示词优化方法 GEPA。
*   **针对性是关键**：仅训练 2-4 个针对性适配器（每个仅更新 5.3% 的参数）即可获得巨大收益，证明了“识别缺陷-针对训练”路径的正确性。

### 7. 优点
*   **自动化闭环**：实现了从失败分析到环境生成再到模型训练的全自动化。
*   **模块化**：通过 LoRA 适配器和路由机制，避免了多能力训练时的灾难性遗忘或干扰。
*   **数据效率**：相比于盲目增加合成数据，TRACE 通过精准定位缺陷，极大地提高了强化学习的样本效率。

### 8. 不足与局限
*   **路由开销**：推理时需要先进行一次分类选择，虽然开销较小，但在极高性能要求的场景下仍需考虑。
*   **依赖分析模型**：系统的高度自动化依赖于一个足够强大的 LLM 来进行失败分析和环境合成，如果分析模型本身存在偏见，可能会识别错误的能力。
*   **能力重叠**：虽然尝试隔离能力，但在复杂任务中，不同能力之间可能存在定义上的重叠，导致路由决策困难。
