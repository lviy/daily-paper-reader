## 摘要
随着大语言模型智能体从软件工程（SWE）任务向机器学习工程（MLE）任务迈进，验证智能体行为的成本呈数量级增长：SWE任务可以通过快速执行的单元测试进行验证，而MLE验证则需要在每个rollout步骤中在大型数据集上运行完整的机器学习流水线——包括数据预处理、模型训练和指标评估——这使得基于轨迹的在线强化学习（on-policy RL）变得极其缓慢。现有方法退而求其次，采用监督微调（SFT）或离线代理奖励，牺牲了在线强化学习在探索和泛化方面的优势。我们观察到，沙盒数据规模是这一瓶颈的主要来源。基于这一洞察，我们推出了SandMLE，这是一个多智能体框架，能够从少量种子任务中生成多样化且可验证的合成MLE环境，在保留现实世界问题的结构和技术复杂性的同时，将数据集限制在微观规模（每个任务仅配有50-200个训练样本）。通过广泛的实验，我们证明SandMLE将执行时间缩短了13倍以上，首次在MLE领域实现了大规模、基于轨迹的在线强化学习。在MLE-bench-lite上，SandMLE在Qwen3-8B、14B和30B-A3B模型上均比SFT基准取得了显著提升，相对奖牌率提升幅度在20.3%到66.9%之间。此外，训练后的策略在未见的智能体脚手架上具有良好的泛化性，在MLE-Dojo上的HumanRank评分提升了高达32.4%。

## Abstract
As large language model agents advance beyond software engineering (SWE) tasks toward machine learning engineering (MLE), verifying agent behavior becomes orders of magnitude more expensive: while SWE tasks can be verified via fast-executing unit tests, MLE verification requires running full ML pipelines -- data preprocessing, model training, and metric evaluation -- on large datasets at each rollout step, rendering trajectory-wise on-policy reinforcement learning (RL) prohibitively slow. Existing approaches retreat to supervised fine-tuning (SFT) or offline proxy rewards, sacrificing the exploration and generalization benefits of on-policy RL. We observe that sandbox data size is the primary source of this bottleneck. Based on this insight, we introduce SandMLE, a multi-agent framework that generates diverse, verifiable synthetic MLE environments from a small number of seed tasks, preserving the structural and technical complexity of real-world problems while constraining datasets to micro-scale (each task is paired with only 50-200 training samples). Through extensive experiments, we show that SandMLE reduces execution time by over 13 times, enabling large-scale, on-policy trajectory-wise RL for the first time in the MLE domain. On MLE-bench-lite, SandMLE yields significant gains over SFT baselines across Qwen3-8B, 14B, and 30B-A3B, with relative medal rate improvements ranging from 20.3% to 66.9%. Furthermore, the trained policy generalizes across unseen agentic scaffolds, achieving up to 32.4% better HumanRank score on MLE-Dojo.

### 1. 核心问题与整体含义（研究动机和背景）
论文聚焦于**机器学习工程（MLE）智能体**的训练瓶颈。与软件工程（SWE）不同，MLE任务的验证极其耗时：SWE可以通过秒级的单元测试验证，而MLE需要运行完整的数据预处理、模型训练和评估流水线。在标准基准测试中，单次代码执行平均耗时近200秒。
这种高延迟使得**在线强化学习（On-policy RL）**在MLE领域几乎不可行，因为RL需要成千上万次的采样（Rollouts）。现有研究大多被迫采用监督微调（SFT）或离线奖励，导致模型缺乏探索能力和泛化性。本文的核心动机是通过**合成微缩环境**来打破这一效率瓶颈。

### 2. 方法论：SandMLE 框架
核心思想是：**MLE任务的延迟主要由数据集规模决定，而非逻辑复杂度。** SandMLE通过多智能体协作，将原始大型任务转化为保持逻辑复杂度但数据量极小（50-200个样本）的合成沙盒。

*   **多智能体生成流水线：**
    *   **数据策略师 (Data Strategist)：** 从种子任务中提取“结构DNA”（如数据模态、标签分布），并将其映射到新的行业场景，注入数学隐藏规则和噪声。
    *   **MLE开发者 (ML Developer)：** 编写代码生成微缩数据集，并根据隐藏规则确定地面真值（Ground Truth），同时建立性能基准。
    *   **MLOps工程师 (MLOps Engineer)：** 构建自动化的评分沙盒，确保评估过程确定且安全。
    *   **技术作家 (Technical Writer)：** 编写任务说明文档，确保提示词与合成环境完全对齐。
*   **关键技术细节：**
    *   **基于里程碑的密集奖励 (Milestone-based Reward)：** 为了解决奖励稀疏问题，设计了包含格式奖励、执行奖励和分级性能里程碑（如中位数、铜/银/金牌水平）的综合奖励函数。
    *   **轨迹级 GRPO：** 使用群组相对策略优化（GRPO）算法，在合成环境上进行多轮交互训练，仅对模型生成的推理和动作Token计算梯度。

*   **数据集：** 以 MLE-bench 的 60 个任务为种子，生成了 **848 个合成训练任务**。

### 5. 实验数量与充分性
*   **实验规模：** 涵盖了从 8B 到 30B 三个参数量级的模型，并在两个主流 MLE 基准上进行了测试。
*   **充分性：** 
    *   进行了**跨框架泛化实验**（在 ReAct, AIDE, AIRA, MLE-Agent 等不同脚手架上测试），证明了提升源于模型能力而非特定框架。

### 6. 主要结论与发现
*   **效率提升：** SandMLE 将平均执行时间从 196 秒缩短至 14 秒，**加速超过 13 倍**，使在线 RL 变得实用。
*   **性能飞跃：** 在 MLE-bench-lite 上，SandMLE 相比 SFT 基准将相对奖牌率提升了 **20.3% 至 66.9%**。
*   **以小博大：** 经过 SandMLE 训练的 Qwen3-8B 模型在奖牌率上达到了与 DeepSeek-V3.1 和 Gemini-2.5-Flash 相当的水平。
*   **泛化性：** 模型在未见的智能体脚手架上表现稳健，克服了 SFT 模型容易出现的“格式崩溃”和“策略脆弱”问题。

### 7. 优点与亮点
*   **创新视角：** 敏锐捕捉到“数据规模是 MLE 训练瓶颈”这一关键点，通过“微缩沙盒”巧妙绕过算力障碍。
*   **全自动流水线：** 提出了一套完整的多智能体协作方案，能够从极少量种子数据扩增出大量高质量、可验证的训练任务。
*   **实战导向：** 训练出的模型不仅在指标上提升，更展现出了在真实工程环境中的“试错”和“自我修正”能力。

### 8. 不足与局限
*   **上下文瓶颈：** 实验发现，随着交互轮数增加，性能会受限于模型的上下文窗口长度，导致长程记忆丢失。
*   **合成与真实的鸿沟：** 虽然微缩数据集保留了数学逻辑，但真实世界中“大数据量”带来的特定工程挑战（如内存管理、分布式训练优化）在合成沙盒中可能无法完全模拟。
*   **模态分布：** 训练数据中图像和表格占比较高（约 73%），对于音频、图数据等稀有模态的覆盖相对较薄弱。
