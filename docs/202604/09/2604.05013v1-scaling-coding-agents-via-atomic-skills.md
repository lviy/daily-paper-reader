## 摘要
当前的大语言模型（LLM）编程智能体主要在复合基准测试（如错误修复）上进行训练，这往往导致针对特定任务的过拟合以及有限的泛化能力。为解决这一问题，我们提出了一种新颖的扩展范式，将重点从任务级优化转向原子技能的掌握。我们首先形式化了五种基础原子技能：代码定位、代码编辑、单元测试生成、问题复现和代码审查，它们作为复杂软件工程任务的基础向量。与复合编程任务相比，这些原子技能具有更强的泛化性和可组合性。然后，我们通过对原子技能进行联合强化学习（RL）来扩展编程智能体。通过这种方式，原子技能得到了持续提升，且彼此之间没有负面干扰或权衡。值得注意的是，我们观察到这些原子技能的提升能够很好地泛化到其他未见的复合编程任务中，例如错误修复、代码重构、机器学习工程和代码安全。这一观察结果为通过原子技能训练来扩展编程智能体提供了一种新的范式。广泛的实验证明了我们所提范式的有效性。值得注意的是，我们的联合强化学习在 5 项原子技能和 5 项复合任务上的平均性能提升了 18.7%。

## Abstract
Current LLM coding agents are predominantly trained on composite benchmarks (e.g., bug fixing), which often leads to task-specific overfitting and limited generalization. To address this, we propose a novel scaling paradigm that shifts the focus from task-level optimization to atomic skill mastery. We first formalize five fundamental atomic skills, code localization, code editing, unit-test generation, issue reproduction, and code review, that serve as the basis vectors for complex software engineering tasks. Compared with composite coding tasks, these atomic skills are more generalizable and composable. Then, we scale coding agents by performing joint RL over atomic skills. In this manner, atomic skills are consistently improved without negative interference or trade-offs between them. Notably, we observe that improvements in these atomic skills generalize well to other unseen composite coding tasks, such as bug-fixing, code refactoring, machine learning engineering, and code security. The observation motivates a new scaling paradigm for coding agents by training with atomic skills. Extensive experiments demonstrate the effectiveness of our proposed paradigm. Notably, our joint RL improves average performance by 18.7% on 5 atomic skills and 5 composite tasks.

### 1. 核心问题与整体含义
*   **研究动机**：当前的 LLM 编程智能体（Coding Agents）主要针对复合任务（如完整的 Bug 修复）进行训练。这种“黑盒”训练方式导致模型容易产生任务特定的过拟合，学习到的是脆弱的启发式规则而非稳健的解决问题能力，且难以泛化到未见过的复杂任务。
*   **核心问题**：如何通过一种可扩展的范式，让编程智能体掌握更具通用性和组合性的基础能力，从而提升其在各种复杂软件工程任务中的表现？

### 2. 方法论
*   **核心思想**：将复杂的软件工程工作流分解为一组**原子技能（Atomic Skills）**，并将其视为解决任何编程任务的“基向量”。通过对这些原子技能进行**联合强化学习（Joint RL）**，实现能力的规模化扩展。
*   **五大原子技能**：
    1.  **代码定位 (Code Localization)**：给定问题描述，识别需要修改的文件列表。
    2.  **代码编辑 (Code Editing)**：根据指令生成补丁，通过自动化测试验证正确性。
    3.  **单元测试生成 (Unit-Test Generation)**：生成能检测出代码缺陷（变异体）的有效测试用例。
    4.  **问题复现 (Issue Reproduction)**：构建最小可执行脚本，在原始代码上触发错误并在修复后消失。
    5.  **代码审查 (Code Review)**：对拉取请求（PR）进行语义分析并给出正确性判断。
*   **关键技术细节**：
    1.  **统一任务接口**：所有技能共享相同的 Agent 接口，通过 Bash 命令和文件编辑工具与环境交互。
    2.  **联合强化学习框架**：使用 **GRPO (Group-based Relative Policy Optimization)** 算法。从统一的技能缓冲池中采样任务，在单一策略下进行优化，促进技能间的正向迁移。
    3.  **沙盒执行环境**：构建了基于 Kubernetes 的大规模沙盒，支持 10,000+ 并发实例，确保奖励信号基于真实的执行结果而非文本相似度。

### 3. 实验设计
*   **基座模型**：GLM-4.5-Air-Base（总参数 106B，激活参数 12B）。
*   **数据集/场景**：
    *   **分布内 (IID) 任务**：上述五项原子技能的评估集。
    *   **分布外 (OOD) 复合任务**：SWE-bench Verified（Bug 修复）、SWE-bench Multilingual（多语言修复）、Terminal-Bench 2.0（终端操作）、Code Refactoring（代码重构，自建基准）、SEC-bench（安全漏洞复现）。
*   **对比方法**：
    *   GLM-4.5-Air（强大的思考模型基准）。
    *   Base + SFT（仅经过原子技能监督微调的模型）。
    *   单任务 RL（如仅针对代码编辑或仅针对 SWE-bench 进行强化学习）。

### 4. 资源与算力
*   **算力细节**：文中未明确给出具体的 GPU 型号（如 A100/H100）和确切的训练总时长。

### 5. 实验数量与充分性
*   **实验规模**：涵盖了 10 个评估任务（5 原子 + 5 复合），每个任务报告 3 次运行的平均值（Avg@3）。
*   **消融实验**：对比了“联合 RL”与“单任务 RL”，证明了联合训练在保持特定任务性能的同时，具有更强的泛化能力。
*   **充分性评价**：实验设计较为充分，通过跨领域（安全、重构、多语言）的 OOD 测试验证了原子技能的“基向量”属性。同时，进行了严格的数据去重（Decontamination），确保模型没有见过测试集的代码仓库。

### 6. 主要结论与发现
*   **原子技能可扩展性**：通过联合 RL，所有原子技能均实现了单调提升，且技能间没有出现负面干扰。
*   **组合泛化性**：原子技能的提升能显著增强模型在未见过的复合任务上的表现。联合 RL 使平均性能提升了 **18.7%**。
*   **优于单任务优化**：相比于直接在 SWE-bench 上进行强化学习，训练原子技能能产生更全面的能力提升，避免了对单一基准分布的过拟合。

### 7. 优点
*   **范式创新**：提出从“任务级优化”转向“技能级优化”，为编程智能体的 Scaling Law 提供了新路径。
*   **执行驱动**：奖励函数完全基于代码执行、日志分析和变异测试，比传统的文本匹配更客观、更接近真实开发场景。
*   **工程严谨**：构建了极其复杂的自动化评估和训练基础设施，解决了 Agent RL 训练中的环境隔离和吞吐量瓶颈。

### 8. 不足与局限
*   **技能覆盖范围**：目前仅定义了 5 种原子技能，虽然具有代表性，但可能尚未覆盖软件工程的所有维度（如架构设计、跨文件依赖的复杂重构等）。
*   **算力门槛极高**：该方法依赖于大规模并发沙盒环境，普通研究机构难以复现这种规模的 Agent RL 训练。
*   **SFT 数据依赖**：RL 的起点依赖于高质量的 SFT 轨迹，如果初始 SFT 数据存在偏差，可能会影响后续 RL 的探索效率。
