## 摘要
智能体技能是程序性知识和可执行资源的结构化包，智能体在推理时动态加载这些技能，已成为增强大语言模型（LLM）智能体的可靠机制。然而，推理时的技能增强存在根本局限：检索噪声会引入无关指导，注入的技能内容会带来巨大的 Token 开销，且模型从未真正习得它仅仅是在遵循的知识。我们探讨技能是否可以内化到模型参数中，从而在无需任何运行时技能检索的情况下实现零样本自主行为。我们提出了 SKILL0，这是一个专为技能内化设计的上下文强化学习框架。SKILL0 引入了一种训练阶段的课程学习方案，从完整的技能上下文开始并逐步撤回。技能在离线状态下按类别分组，并与交互历史一起渲染成紧凑的视觉上下文，教导模型进行工具调用和多轮任务完成。随后，动态课程会评估每个技能文件的同策略（on-policy）帮助程度，在呈线性衰减的预算内仅保留当前策略仍能从中获益的技能，直到智能体在完全零样本的设置下运行。广泛的智能体实验表明，SKILL0 相比标准强化学习基线取得了显著改进（ALFWorld 提升 9.7%，Search-QA 提升 6.6%），同时保持了每步少于 0.5k Token 的高效上下文。我们的代码可在 https://github.com/ZJU-REAL/SkillZero 获取。

## Abstract
Agent skills, structured packages of procedural knowledge and executable resources that agents dynamically load at inference time, have become a reliable mechanism for augmenting LLM agents. Yet inference-time skill augmentation is fundamentally limited: retrieval noise introduces irrelevant guidance, injected skill content imposes substantial token overhead, and the model never truly acquires the knowledge it merely follows. We ask whether skills can instead be internalized into model parameters, enabling zero-shot autonomous behavior without any runtime skill retrieval. We introduce SKILL0, an in-context reinforcement learning framework designed for skill internalization. SKILL0 introduces a training-time curriculum that begins with full skill context and progressively withdraws it. Skills are grouped offline by category and rendered with interaction history into a compact visual context, teaching he model tool invocation and multi-turn task completion. A Dynamic Curriculum then evaluates each skill file's on-policy helpfulness, retaining only those from which the current policy still benefits within a linearly decaying budget, until the agent operates in a fully zero-shot setting. Extensive agentic experiments demonstrate that SKILL0 achieves substantial improvements over the standard RL baseline (+9.7\% for ALFWorld and +6.6\% for Search-QA), while maintaining a highly efficient context of fewer than 0.5k tokens per step. Our code is available at https://github.com/ZJU-REAL/SkillZero.

### 1. 核心问题与研究动机
*   **研究背景**：当前提升大语言模型（LLM）智能体能力的主流方式是“推理时技能增强”，即通过检索算法从技能库中提取相关指令并注入 Prompt。
*   **核心痛点**：
    1.  **检索噪声**：无关或误导性的技能描述会干扰模型决策。
    2.  **Token 开销**：在多轮对话中注入大量技能描述会导致计算成本激增。
    3.  **缺乏真实习得**：模型只是在“遵循”指令，而非真正“掌握”知识，导致其对外部上下文产生永久性依赖。
*   **研究目标**：探索技能是否可以被“内化”到模型参数中，实现“训练时有技能参考，推理时零技能依赖”的自主行为。

### 2. 方法论：SKILL0 框架
SKILL0 提出了一种**上下文强化学习（In-Context Reinforcement Learning, ICRL）**框架，核心思想是利用技能作为训练时的“脚手架”，并在训练过程中逐步拆除。
*   **视觉上下文渲染（Context Rendering）**：为了降低 Token 成本，将交互历史和技能文本渲染为紧凑的视觉图像，由视觉编码器处理。模型可自适应生成压缩率 $c_t$。
*   **动态课程学习（Dynamic Curriculum）**：
    1.  **线性预算衰减**：设定一个随训练步数线性减少的技能数量上限 $M(s)$。
    2.  **帮助度评估（Helpfulness Evaluation）**：通过对比“有技能”和“无技能”下的验证集表现，计算每个技能文件的增益 $\Delta k = Acc_{w/skill} - Acc_{w/o skill}$。
    3.  **过滤与排序**：在预算范围内，仅保留 $\Delta k > 0$ 且排名靠前的技能。
*   **强化学习优化**：采用类似 GRPO 的算法，结合任务成功奖励和 Token 压缩奖励，直接优化模型参数，促使知识从上下文向参数转移。

### 6. 主要结论与发现
*   **性能飞跃**：在零样本推理设置下，SKILL0 在 ALFWorld 上比 AgentOCR 提升了 **9.7%**，在 Search-QA 上提升了 **6.6%**。
*   **极高效率**：推理时无需检索技能，每步 Token 消耗控制在 **0.5k 以下**，比 SkillRL 等方法节省了 5 倍以上的计算成本。
*   **内化规律**：实验观察到技能的“帮助度”随训练呈现“先升后降”的趋势——早期模型学习如何利用技能，后期模型因知识已内化，外部技能的边际增益趋近于零。

### 7. 优点与亮点
*   **范式转移**：从“如何更好地检索技能”转向“如何摆脱对技能检索的依赖”，具有前瞻性。
*   **动态自适应**：引入的帮助度评估机制确保了撤回技能的过程是平滑且符合模型学习进度的，避免了硬性课程导致的性能崩溃。
*   **视觉压缩集成**：巧妙地利用视觉编码器处理长历史，解决了智能体任务中常见的上下文爆炸问题。

### 8. 不足与局限
*   **初始依赖**：SKILL0 的效果高度依赖于初始技能库（SkillBank）的质量，如果初始技能有误，内化的知识也会有偏差。
*   **冷启动成本**：在应用到全新领域时，需要预先进行离线技能分组和验证集划分，存在一定的工程准备成本。
*   **视觉细节丢失风险**：虽然视觉渲染降低了 Token，但在极少数需要精确文本匹配的场景下，视觉编码可能不如原始文本精确。
