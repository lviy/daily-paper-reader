## 摘要
大语言模型（LLMs）日益依赖智能体能力——如迭代检索、工具使用和决策——来克服静态参数化知识的局限性。然而，现有的智能体框架将外部信息视为非结构化文本，未能利用现实世界数据中固有的拓扑依赖关系。为了弥补这一差距，我们引入了智能体图学习（Agentic Graph Learning, AGL），这是一种将图学习重新定义为拓扑感知导航与基于 LLM 推理的交替过程的范式。具体而言，我们提出了 AgentGL，这是首个针对 AGL 的强化学习（RL）驱动框架。AgentGL 为 LLM 智能体配备了用于多尺度探索的图原生工具，通过搜索约束思维来规范工具使用以平衡准确性与效率，并采用图条件课程强化学习策略，在无需逐步监督的情况下稳定长程策略学习。在多种文本属性图（TAG）基准测试和多个 LLM 主干模型上，AgentGL 显著优于强力的 GraphLLMs 和 GraphRAG 基准模型，在节点分类中实现了高达 17.5% 的绝对提升，在链路预测中实现了 28.4% 的提升。这些结果表明，AGL 是使 LLM 能够在复杂关系环境中自主导航和推理的一个极具前景的前沿方向。代码已公开于 https://github.com/sunyuanfu/AgentGL。

## Abstract
Large Language Models (LLMs) increasingly rely on agentic capabilities-iterative retrieval, tool use, and decision-making-to overcome the limits of static, parametric knowledge. Yet existing agentic frameworks treat external information as unstructured text and fail to leverage the topological dependencies inherent in real-world data. To bridge this gap, we introduce Agentic Graph Learning (AGL), a paradigm that reframes graph learning as an interleaved process of topology-aware navigation and LLM-based inference. Specifically, we propose AgentGL, the first reinforcement learning (RL)-driven framework for AGL. AgentGL equips an LLM agent with graph-native tools for multi-scale exploration, regulates tool usage via search-constrained thinking to balance accuracy and efficiency, and employs a graph-conditioned curriculum RL strategy to stabilize long-horizon policy learning without step-wise supervision. Across diverse Text-Attributed Graph (TAG) benchmarks and multiple LLM backbones, AgentGL substantially outperforms strong GraphLLMs and GraphRAG baselines, achieving absolute improvements of up to 17.5% in node classification and 28.4% in link prediction. These results demonstrate that AGL is a promising frontier for enabling LLMs to autonomously navigate and reason over complex relational environments. The code is publicly available at https://github.com/sunyuanfu/AgentGL.

#### 1. 核心问题与整体含义

**核心问题**：如何构建一个能够自主导航原生图结构、积累结构化证据并迭代优化推理路径的智能体图学习（Agentic Graph Learning, AGL）范式？

#### 2. 方法论
论文提出了 **AgentGL**，这是首个由强化学习（RL）驱动的 AGL 框架。其核心思想是将图学习建模为一个交互式的决策过程。

*   **图原生搜索工具集（GNS Tools）**：
    *   **1-hop/2-hop 搜索**：基于拓扑邻域获取局部证据，通过语义嵌入和查询相关性进行重排序。
    *   **结构显著性搜索（SS）**：利用 PageRank（PPR）分数检索全局关键节点。
    *   **图稠密搜索（Dense）**：利用语义相似度跨越拓扑限制检索相关节点。
*   **两阶段强化学习策略**：
    *   **阶段 1：策略引导（Bootstrapping）**：通过奖励塑造（包括格式奖励、准确性奖励和工具覆盖率奖励）引导模型学会使用图原生工具。
    *   **阶段 2：缓解过度搜索（MSO）**：引入“搜索约束思维”（Search-Constrained Thinking），通过回顾性终止触发器和认知密度正则化，惩罚冗余搜索，鼓励深度推理。
*   **图条件课程学习（GCCL）**：
    *   根据图的拓扑先验（如节点分类中的同质性和度数，利用 Wilson 下界区间估计难度）和语义先验（链路预测中的相似度一致性）设计由易到难的训练序列，以稳定长程策略学习。
*   **优化算法**：采用了 GRPO 和 REINFORCE++ 两种主流的无评论器（critic-free）策略优化算法。

#### 3. 实验设计
*   **数据集**：涵盖 3 个领域的 7 个 TAG 基准数据集：

*   **任务场景**：节点分类（NC）和链路预测（LP），包括**域内评估**和**零样本迁移（Zero-shot Transfer）**。

#### 5. 实验数量与充分性
实验设计非常充分且具有客观性：

*   **泛化性测试**：专门设置了零样本迁移实验，验证模型在未见过的图领域上的策略迁移能力。

#### 6. 主要结论与发现
*   **性能卓越**：AgentGL 在节点分类上平均提升 12.7%-24.4%，在链路预测上平均提升 22.4%-26.3%，显著优于静态上下文方法。
*   **效率与准确性的平衡**：通过第二阶段训练，模型在减少约 17.5% 工具调用的同时，准确率反而有所提升，证明了“少即是多”的搜索策略有效。
*   **零样本能力强**：AgentGL 展现了极强的跨领域迁移能力，说明其学到的是通用的图导航和推理策略，而非简单的标签映射。
*   **模型规模效应**：随着主干模型从 3B 扩展到 7B，智能体的图学习能力和泛化能力显著增强。

#### 7. 优点
*   **范式创新**：首次将图学习定义为智能体自主导航过程，并用 RL 进行端到端优化。
*   **工具设计完备**：结合了局部拓扑、全局结构和语义关联，覆盖了图信息检索的多个维度。
*   **训练策略科学**：引入课程学习解决图数据中的噪声和长程依赖导致的训练不稳定问题。
*   **实用性强**：不依赖昂贵的 SFT 轨迹标注，通过程序化奖励即可实现高性能。

#### 8. 不足与局限
*   **模态限制**：目前仅支持文本属性图，尚未扩展到包含图像、视频等多模态属性的图结构。
*   **数据分配敏感性**：MSO 阶段的稳定性高度依赖于两个训练阶段之间的数据分配比例。
*   **图密度挑战**：在极稠密的图结构中，智能体可能会面临搜索空间爆炸的问题，文中未深入探讨超大规模稠密图的应对策略。
*   **推理成本**：尽管优化了搜索次数，但多轮 LLM 推理相比传统 GNN 仍有显著的计算延迟。
